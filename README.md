# Install


1. Download arduino IDE
2. get the esp8266 core https://github.com/esp8266/Arduino
3. install esp8266 board manager
    1. choose generic esp8266 board
4. You need a driver to recognize board
    - https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers?tab=downloads
    - May not work but google it
    - once installed select the right Port: ![alt text](image.png)
5. install libraries neomatrix,neopixel, etc
